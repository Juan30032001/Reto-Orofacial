# Juego interactivo de odontología

## Publicar en GitHub Pages

1. Sube el contenido de `Mi-juego/` a tu repositorio.
2. En la configuración del repositorio, activa GitHub Pages y publica desde la rama y carpeta donde colocaste `index.html`.

El juego no necesita Supabase ni claves de servicios externos. La tabla conserva la mejor puntuación por nombre en el almacenamiento local del navegador; por eso cada dispositivo muestra sus propios resultados y no una clasificación compartida.
